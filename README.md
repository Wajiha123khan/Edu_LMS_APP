**ABOUT EDUCORE_LMS**

Admin User Stories
As an Admin,
1) log in securely so that only authorized users can access the admin panel.
2) To view a dashboard so that I can see total students, teachers, courses, and active users.
3) Add, update, and delete students so that student records are always up to date.
4) Add, update, and delete teachers so that teaching staff can be managed easily.
5) create and manage courses so that students can enroll in available courses.
6) Assign teachers to courses so that each course has a responsible instructor.
7) Manage student enrollments so that students are enrolled in correct courses.
8) Activate or deactivate users so that I can control system access.
9) log out securely so that my session is protected.

**Student User Stories**

As a Student,
1) Register and log in so that I can access my account.
2) View my profile so that I can see my personal and academic information.
3) Edit my profile so that my details stay updated.
4) View available courses so that I can choose what to study.
5) Enroll in courses so that I can start learning.
6) view my enrolled courses so that I know what I am studying.
7) See assigned teachers so that I know who is teaching my course.
8) log out so that my account remains secure.

**Teacher User Stories**

As a Teacher,
1) log in so that I can access my teaching dashboard.
2) view my profile so that I can check my personal and professional details.
3) update my profile so that my information is accurate.
4) view assigned courses so that I know which subjects I am teaching.
5) view enrolled students so that I can see who is in my course.
6) manage student progress (optional/future) so that I can track performance.
7) log out securely so that my account is protected.
